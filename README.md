# Feed Path

My news and video feed: the topics I care about and the sources I follow, summarized by Claude with links to every source, as an installable web app for iPhone and Mac. A collector on GitHub Actions does the reading every morning, ready by 10:00 Israel time.

Live: https://itzik-a.github.io/feed-path/ (on the iPhone: open in Safari → Share → Add to Home Screen).
